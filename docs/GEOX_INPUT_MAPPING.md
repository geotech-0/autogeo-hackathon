# GEOX 입력 허용목록과 수동 해석결과 매핑

GEOX 캡처는 편집항목 정의의 참고이며 숫자의 출처가 아닙니다. 현재 로컬 기본값은 제공 구조계산서의 B좌/C/D 단면별 7개 검토안·20개 부재 사례입니다. 입력 수치와 원문 페이지는 `src/data/real-design/catalog.mjs`를 따릅니다. 기존 합성 A현장 초기값은 초기 릴리스의 시험 fixture로 남아 있으며 현재 기본값이 아닙니다.

실자료 전사값의 외부 공개는 승인 전입니다. 기존 공개 URL은 이전 합성판입니다. 파생자료 공개 모드는 계산 수치·출처 페이지를 유지하고 원문 PDF 열람을 로컬 원자료본 안내로 전환합니다.

화면 순서: 자료 확인 → 제원 설정 → 해석값 채택 → 검토와 저장. 계산 순서는 굴착 시공단계와 구별합니다.

## 어스앵커

채택 방법: 일시 앵커 · 자유장+정착장+0.5 m · 설계축력 기준

### 편집 허용 제원

| 화면 항목 | 내부키 | 단위 | 외부 해석 재확인 |
|---|---|---|---|
| 강연선 본수 | `strandCount` | 본 | 변경 시 필요 |
| 자유장 Lf | `adoptedFreeLengthM` | m | 변경 시 필요 |
| 정착장 La | `adoptedAnchorageLengthM` | m | 변경 시 필요 |
| 앵커 수평간격 | `spacingM` | m | 변경 시 필요 |
| 자유장 안전거리 | `freeSafetyDistanceM` | m | 현재 채택 해석값에 대한 부재 검토 |
| 지반 주면마찰저항 τu | `groundFrictionKpa` | kPa | 현재 채택 해석값에 대한 부재 검토 |
| 허용부착응력 τa | `bondStressKpa` | kPa | 현재 채택 해석값에 대한 부재 검토 |
| 앵커 내력 안전율 | `pulloutSafetyFactor` | 배 | 현재 채택 해석값에 대한 부재 검토 |
| PC강선 활동량 | `slipMm` | mm | 현재 채택 해석값에 대한 부재 검토 |

### 수동 채택 해석값

| 화면/외부 출력의 의미 | 내부키 | 지원 단위 | 방향과 부호 |
|---|---|---|---|
| 최대 축방향 반력 R′ | `reactionKnPerM` | kN/m, kN/개 | 앵커 축방향 · 인장 양(+) |

### 읽기 전용 조건

- 재료·강연선: SWPC7B / Ø12.7 mm / 1본 면적98.71 mm²
- 강도·탄성계수: fpy1,570 / fpu1,860 / Ep200,000 MPa
- 허용인장력: min(0.65 fpu, 0.80 fpy)
- 긴장손실 길이: 자유장 + 정착장 + 0.5 m
- 자유장 기하 채택값: 선택 단면·앵커 단의 원문 값(예: B좌 1단 4.166 m). 초기 합성 fixture의 3.6 m와 구분
- 정착장 범위: 3~10 m / 천공경100 mm

- 설치각을 반영한 축방향 반력입니다. 수평반력을 입력하거나 각도를 다시 보정하지 않습니다.
- 파괴면까지의 기하 길이는 고정 채택값입니다. 새 파괴면 해석은 수행하지 않습니다.

## 띠장

채택 방법: 상단 분담 모델 · 연속보 · 등분포하중

### 편집 허용 제원

| 화면 항목 | 내부키 | 단위 | 외부 해석 재확인 |
|---|---|---|---|
| 계산지간 L | `spanMm` | mm | 변경 시 필요 |
| 브래킷 전체 거리 a | `leverAMm` | mm | 현재 채택 해석값에 대한 부재 검토 |
| 작용점~하단 거리 c | `leverCMm` | mm | 현재 채택 해석값에 대한 부재 검토 |
| 가설 허용응력 보정 | `temporaryFactor` | 배 | 현재 채택 해석값에 대한 부재 검토 |
| 재사용·부식 계수 | `reuseFactor` | 배 | 현재 채택 해석값에 대한 부재 검토 |

### 수동 채택 해석값

띠장은 연결된 앵커의 손실 포함 초기긴장력 Jf[kN/개]를 자동 채택합니다. 앵커의 입력개정과 지문을 함께 보존하며 독립 수동 반력으로 덮어쓰지 않습니다.

### 읽기 전용 조건

- 재료·단면: SS275 / H298×201×9/14
- 휨 단면계수 Zx: 893,000 mm³
- 전단 유효면적 Aw: 2,430 mm²
- 앵커 설치각: 수평면에서35° · 현재 실제 원문 검토안 채택값. 초기 합성 fixture는 30°
- 보 모델: 연속보 kR1.1 / kM0.1 / kV0.6
- 단면 구성: 2H 상단 분담 c/a · a/2≤c<a

- 집중하중·단순보·다른 단면개수는 이번 계산방법에서 지원하지 않습니다.
- 이음·브래킷·접합부 및 하단 띠장 강도는 별도 검토 대상입니다.

## H-Pile

채택 방법: 강축 부재 검토 · 채택 변위 비교 · Qu 직접 입력

### 편집 허용 제원

| 화면 항목 | 내부키 | 단위 | 외부 해석 재확인 |
|---|---|---|---|
| 말뚝 수평간격 | `spacingM` | m | 변경 시 필요 |
| 말뚝 비지지길이 | `unbracedLengthMm` | mm | 변경 시 필요 |
| 극한지지력 Qu | `ultimateBearingKn` | kN | 현재 채택 해석값에 대한 부재 검토 |
| 지지력 안전율 Fs | `bearingSafetyFactor` | 배 | 현재 채택 해석값에 대한 부재 검토 |
| 가설 허용응력 보정 | `allowableFactor` | 배 | 현재 채택 해석값에 대한 부재 검토 |
| 재사용·부식 계수 | `reuseFactor` | 배 | 현재 채택 해석값에 대한 부재 검토 |
| 굴착깊이 대비 허용변위율 | `displacementLimitPercent` | % | 현재 채택 해석값에 대한 부재 검토 |

### 수동 채택 해석값

| 화면/외부 출력의 의미 | 내부키 | 지원 단위 | 방향과 부호 |
|---|---|---|---|
| 압축축력 N | `axialForceKn` | kN/본 | 말뚝 축방향 · 압축 양(+) |
| 최대모멘트 M′ | `momentPerMKnm` | kN·m/m, kN·m/본 | 강축 휨 · 원시부호 보존 후 절대최대 |
| 최대전단력 V′ | `shearPerMKn` | kN/m, kN/본 | 벽체 수평방향 · 원시부호 보존 후 절대최대 |
| 최대 수평변위 δ | `displacementMm` | mm, m | 수평변위 · 원시부호 보존 후 절대최대 |

### 읽기 전용 조건

- 강재·단면: SHP275(W) / H300×300×10×15
- 단면성능: A11,980 mm² / Zx1,360,000 mm³
- 전단·회전반경: Aw2,700 mm² / Rx131 mm
- 지지조건: Lc=Lb=입력 비지지길이 · 강축
- 변위 검토 굴착깊이 H: B좌 9.31 m, C 9.71 m, D 8.31 m. D는 원문 시공단계의 3.31 m와 충돌하므로 원문 불일치 상태를 보존. 초기 합성 fixture의 10 m와 구분
- 지지력 방법: 직접 채택한 Qu / Fs · 경험식 미혼합

- M′·V′·변위의 지배단계가 다를 수 있습니다. 성분별 최대값에 대한 포락 검토입니다.
- 약축·국부좌굴·접합부와 굴착 전체 안정은 포함하지 않습니다.

## 토류판

채택 방법: 선택 단면의 원문 검토깊이 · 단순지지 · 등분포 면압. B좌/C/D 깊이는 위 H 항목을 따릅니다.

### 편집 허용 제원

| 화면 항목 | 내부키 | 단위 | 외부 해석 재확인 |
|---|---|---|---|
| 토류판 높이 H | `heightMm` | mm | 변경 시 필요 |
| 토류판 두께 t | `thicknessMm` | mm | 변경 시 필요 |
| H-Pile 수평간격 | `spacingMm` | mm | 변경 시 필요 |
| H-Pile 폭 b | `pileWidthMm` | mm | 변경 시 필요 |
| 목재 허용휨응력 | `allowableMpa` | MPa | 현재 채택 해석값에 대한 부재 검토 |
| 목재 허용전단응력 | `allowableShearMpa` | MPa | 현재 채택 해석값에 대한 부재 검토 |

### 수동 채택 해석값

| 화면/외부 출력의 의미 | 내부키 | 지원 단위 | 방향과 부호 |
|---|---|---|---|
| 검토구간 최대 면압 p | `pressureKpa` | kPa, MPa, kN/m | 토류판에 작용하는 면압 · 양(+) |

### 읽기 전용 조건

- 설계지간: L=s−3b/4 · 자동계산
- 지지·하중: 양단 단순지지 · 균일 직사각형 · 등분포
- 토압 입력: 면압kPa → 판높이를 곱해 선하중kN/m
- 토압 감소/되메움 옵션: 미적용 · 별도 모드 지원 안 함
- 전단 표시: 채택 평균전단 + 직사각형 최대전단 구분

- 입력값은 면압입니다. 선하중kN/m 입력 시 현재 판높이로 나누어 면압으로 환산합니다.
- 필요두께는 휨·전단 검토값이며 처짐·연결부까지 고려한 최종 채택두께는 아닙니다.

## 외부 출력명과 변환 규칙

실제 외부 프로그램의 파일을 자동 읽는 연결은 없습니다. 사용자가 출력의 축·폭·부호를 확인하고 아래 의미에 맞춰 채택합니다. 확인하지 못한 다른 버전의 출력명을 같다고 단정하지 않습니다.

| 외부 출력 의미 | 앱에서 채택하는 값 | 실제 변환 |
|---|---|---|
| 앵커 최대 축방향 반력 | R′, kN/m | Treq=R′×수평간격. 설치각을 다시 곱하지 않음. 1개당 kN이면 간격으로 정규화 후 원시값 보존 |
| 앵커 손실 포함 초기긴장력 | Jf, kN/개 | 띠장 연결 하중. 손실 전 Treq 또는 R′와 구분. 간격을 중복 곱하지 않음 |
| 측면말뚝 최대 휨모멘트 | M′, kN·m/m | 간격을 한 번 곱해 kN·m/본. 1본 입력이면 중복 환산하지 않음 |
| 측면말뚝 최대 전단력 | V′, kN/m | 간격을 한 번 곱해 kN/본 |
| 말뚝 압축 축력 | N, kN/본 | 1본의 채택 축력. 하중 세목을 자동 합산하지 않음 |
| 최대 수평변위 | δ, mm | m이면 ×1000. 원시부호 보존 후 절대크기를 기준과 비교 |
| 토류판 검토구간 최대 토압 | 면압 p, kPa | MPa이면 ×1000. w=p×판높이[m]. 선하중으로 받은 경우 높이로 나누어 정규화 |
| 별도 지지력 검토의 극한값 | Qu, kN/본 | Qa=Qu/Fs. SPT 경험식을 다시 혼합하지 않음 |

## 출처·개정과 변경 규칙

각 수동 성분에 원시값, 입력 단위, 지배 시공단계, 위치, 근거를 저장합니다. 공통 출처에는 자료ID/개정, 프로그램/버전, 모델ID/개정, 해석 실행일, 입력자, 포락방법을 저장합니다. M/V/δ가 서로 다른 지배단계이면 성분별 포락임을 표시하며 동시 조합으로 바꾸지 않습니다.

간격·비지지길이·자유장·정착장 또는 모델 ID/개정이 바뀌면 현재 결과는 해석 재확인 상태가 됩니다. 명시적으로 호환성을 확인한 후 채택합니다. 새 탄소성해석을 수행했다는 의미가 아닙니다. 앵커 입력 변경 시 Jf와 연결 띠장을 전체 정밀도로 재계산하고 화면에서만 반올림합니다.

재료/단면의 추가 선택지, 앵커 다른 길이 방식, 띠장 단순보/집중하중/접합부, 말뚝 약축·국부좌굴, 흙막이 전체 안정·침하·근입·보일링·파이핑의 자동 재해석은 활성 계산 기능에 포함하지 않습니다. 별도 계산서 검토 화면에서 제공된 원문 결과·페이지를 확인할 수 있으나 사용자가 바꾼 조건으로 해당 결과가 재계산되지는 않습니다.
