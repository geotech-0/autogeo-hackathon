# 재사용과 신규 기여

| 기존 작업 | 이번 사용 | 이번 신규 구현 |
|---|---|---|
| 지반/부재 설계 도구 | 앵커·띠장·말뚝·토류판의 선정 산술 커널을 분리·수정 | GEOX 허용목록, 수동해석 출처/단위/개정, Qu 직접입력, 앵커→띠장 의존성, 재확인 상태, 안내형 UI·계산서·대안 |
| GroundLink | 현장·구역·자료·분석·조치 연결 개념 참고 | 정적 프런트엔드용 IndexedDB, 개정 snapshot, 원자적 JSON import/export, 공통계약·통합이력. SQLite 서버는 복사하지 않음 |
| 드론 현장 플랫폼 | 좌표 원점/회차/주석 계약 참고, 실제 CAD 정합 근거를 로컬에서 재계산 | API 없는 가벼운 합성 2D 비교, CSV/주석 연결. 실제 회차·대용량 모델은 공개에 미복사 |
| 시공단계 3D | 3D 조작과 업무 화면 방향 참고 | 동일 합성 현장의 kriging mesh·단면·시추공·굴착, 모델 검수와 참고형상 변환 |
| 이번 해커톤 | 사용자 자료와 요구를 근거로 범위 설계 | 품질시험 파서/검토, 계측 이슈, GPR 조사→확인→조치→재점검, GS 참고 UI, 공개 Git/Vercel, 독립검수·발표자료 |

원본 프로젝트는 수정하지 않았다. 재사용 비율·업무시간 절감·현장 정확도는 실제 측정하지 않았으므로 숫자로 주장하지 않는다. 외부 라이브러리의 라이선스는 public/THIRD_PARTY_NOTICES.txt와 public/licenses에 포함했다.
