# 재사용과 신규 기여

현재 문서는 실현장 통합 작업본을 설명한다. 기존 공개 URL/GitHub의 합성판은 이전 릴리스이며, 실제 전사값·좌표·정사영상의 외부 공개는 아직 승인 전이다.

| 기존 작업 | 이번 사용 | 이번 신규 구현 |
|---|---|---|
| 지반/부재 설계 도구 | 앵커·띠장·말뚝·토류판의 선정 산술 커널을 분리·수정 | GEOX 허용목록, 수동해석 출처/단위/개정, 실제 B좌/C/D 7검토안과 20부재 사례, 앵커→띠장 의존성, 재확인 상태·계산서·원문 연결 |
| GroundLink | 현장·구역·자료·분석·조치 연결 개념 참고 | 정적 프런트엔드용 IndexedDB, 개정 snapshot, 원자적 JSON import/export, 첨부 바이트/해시 보존, 공통계약·통합이력. SQLite 서버는 복사하지 않음 |
| 드론 현장 플랫폼 | 원점/주석 계약 참고, 현재 제공 DWG와 해시가 같은 기존 CAD 파싱 결과 재사용 및 정합 재계산 | 실제 정사영상·64타일, DSM, LAS 공간 대표점, CAD 7,988엔티티, GCP 13점 공통 뷰어. 촬영일·수직기준·독립 검사점의 미확인 상태 유지 |
| 시공단계 3D | 3D 조작과 업무 화면 방향 참고 | 실제 4차수 32공·96구간 어댑터, Ordinary kriging 경계면·단면·공별 원문, DSM/점군 별도 보기, 저장·복원. CAD 경계 투영은 완전한 시공 BIM 생성과 구분 |
| 이번 해커톤 | 사용자 제공 보고서·영상·도면·품질 예시와 요구를 근거로 범위 설계 | 실제 계측 3권/27센서·품질 예시 곡선, 자료 불일치와 조치 이력, GPR 첨부→확인→조치→재점검, GS 참고 UI, 검수·발표자료·공개/로컬 원자료 모드 |

초기 합성판에서는 합성 SVG 영상과 12공/4층 모델로 기능 연결·저장을 먼저 검증했다. 이 예제는 구분해서 보존하며 현재 실제 정사영상이나 32공 원자료를 합성이라고 부르지 않는다. 제공 GPR 실측 원자료는 없으므로 유지관리 업무 흐름이 원신호 자동 판독을 구현했다는 뜻은 아니다.

원본 프로젝트와 제공 원본은 수정하지 않았다. 로컬에 PDF9개·주상도 원문47이미지·품질 원자료7개를 유지하며 파생자료 빌드에서는 해당 원문 폴더를 제외한다. 실제 수치·형상 파생자료를 남기는 공개 범위는 별도 확인 대상이다. 대용량 원본 LAS/GeoTIFF/DWG 전체를 공개 폴더에 그대로 복사하지 않고 경량화 파생본을 사용한다.

재사용 비율·업무시간 절감·현장 정확도는 실제 측정하지 않았으므로 숫자로 주장하지 않는다. 외부 라이브러리 고지는 `public/THIRD_PARTY_NOTICES.txt`와 `public/licenses`에 포함한다.
