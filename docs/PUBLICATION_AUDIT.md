## 결과와 후속 항목

현재 검사 범위에서 비공개 원문·현장 좌표·개인 경로·인증 키가 앱 자료로 포함된 징후는 발견하지 못했다. 기본 설계 보고서와 JSON의 합성 출처 유지도 확인했다. 다음 항목은 공개본 확정 전에 남아 있다.

| 항목 | 상태 | 근거 또는 필요한 후속 작업 |
|---|---|---|
| 실제 원자료 분리 | 확인 | 원본 파일명·해시 및 실제 현장 좌표의 정확 문자열 28개를 대조해 일치 없음. 비공개 원자료·추출 이미지 51개와 공개 후보의 SHA-256 일치 없음 |
| 개인 경로·키·개인정보 패턴 | 확인 | 사용자 홈 경로, 원본 현장명, 개인명, 이메일, 주요 키 형식 검사에서 실제 포함 징후 없음. 일치값·키 내용은 감사 출력에 기록하지 않음 |
| 금지 토큰이 포함된 시험 | 분리 확인 | `src/features/design/model.test.mjs`의 `assert.doesNotMatch` 정규식 1건. 원자료 포함을 막는 부정 검증이며 원본 데이터가 아님. 해당 시험은 배포 번들에 포함되지 않음 |
| 기본 자료·보고서·JSON 출처 | 확인 | 아래 출처 경로와 메모리 실행 결과 참조 |

| 최종 공개본 동일성 | **확정 전** | 최신 변경의 빌드, 최종 SHA, 공개 URL·깊은 경로·정적 자산 확인은 통합 담당의 배포 검수 대상 |

보완 확인에서 개인 경로·원본 현장명·이메일·키 패턴과 실제 좌표 28개, 원자료/추출 이미지 51개 해시를 다시 검사했다. 새로운 원자료 포함은 발견하지 못했다. 원본명 패턴의 유일한 일치는 같은 부정 검증 시험이고, 새 번들의 `fetch` 1건도 같은 modulepreload 코드다. 기본 설계 보고서·JSON·가져오기 왕복의 `synthetic` 출처도 재확인했다.

## 출처와 내보내기

### 기본 자료

- 공통 현장은 `synthetic-a`, 구역은 `A-01`, 좌표는 직접 만든 120×100 m 로컬 프레임이다. 초기 `SEED_RECORDS`는 빈 배열이며 안내 카드를 실제 미해결 기록으로 저장하지 않는다.
- 지반 관측공은 `syntheticBoreholes` 생성값이다. 계산 기록의 `origin=calculated`는 계산 방법을 표시하고, `source_id=synthetic-ground-boreholes-v1` 및 `payload.datasetOrigin=synthetic`이 원자료 출처를 보존한다. 사용자 입력은 별도 출처로 저장되며 불러올 때 합성 표시를 유지하려면 합성 좌표·지층값과 일치해야 한다.
- 설계 기본 workspace의 자료 구분, 저장 기록, 입력 JSON은 `synthetic`이다. 보고서에는 합성 시연 데이터 및 수동 외부 해석값을 사용한 부재 후처리라는 범위가 표시된다.
- 평판재하·계측 기본 CSV는 각각 합성 출처와 자료명을 가진다. 파일 업로드 또는 수동 계측 추가 뒤에는 자료 출처를 다시 선택해야 한다. 두 탭의 출처 상태는 분리되어 있다.
- 회차 영상은 코드로 만든 합성 SVG다. GPR 기본 기록·해석도·해석자·측선은 합성 예제로 명시되며, 임시 흙막이와 구분된 준공 후 관리도로 객체를 사용한다.

### 실행 확인

기본 workspace를 메모리에서 생성해 `makeDesignDraft`, `makeRecord`, `makeReport`, `exportDesign`, `importDesign`, `validateArchive`를 실행했다. 별도 파일이나 실제 브라우저 기록을 생성하지 않았다.

| 확인값 | 결과 |
|---|---|
| 기본 설계 자료 / 저장 기록 origin | 모두 `synthetic` |
| 설계 JSON 내보내기→가져오기 origin | `synthetic` 유지 |
| 공통 JSON 검증 왕복 origin | `synthetic` 유지 |
| HTML 보고서의 합성 시연 표시 | 존재 |
| HTML 보고서의 전체 안정·최종 승인 제외 표시 | 존재 |
| 기본 보고서·JSON의 비공개 경로·원문 메타데이터 패턴 | 없음 |
| GPR 기본 origin | `synthetic` |

공통 JSON은 기록과 보관 개정을 그대로 내보내고 가져온 출처 구분을 보존한다. 사용자 입력을 자동 익명화하거나 합성값으로 치환하는 기능은 없다. 따라서 위 결과는 공개 기본 자료에 관한 것이며, 사용자가 나중에 입력한 실제 자료까지 합성이라고 보증하지 않는다. 저장된 자료를 내보내면 그 자료의 입력과 메모도 함께 포함된다.

## 네트워크와 자료 보관

- 런타임은 정적 React/Vite 앱이다. 별도 API 서버, AI API, GEOX 실행 서버, 로컬 파일 서버에 의존하는 코드가 없다. package의 `127.0.0.1`은 개발/미리보기 서버 바인딩이며 공개 앱의 호출 주소가 아니다.
- 코드와 번들에서 발견한 실제 외부 호스트 후보는 CODIL·국가건설기준센터의 사용자가 여는 기준 링크다. 폰트·GS SVG·앱 스크립트는 배포 경로에서 읽는다. 분석·광고 추적 SDK, 자동 센서 전송, GPR 업로드 API는 발견하지 못했다.
- 저장은 IndexedDB의 `records`, `revisions`, `drafts`, `meta`를 사용한다. JSON 가져오기는 구조·현장·개정·출처·유한 수치를 검증하고, 같은 개정에 내용이 다르면 transaction을 취소한다. 이전 개정으로 최신 기록을 덮어쓰지 않는다.
- 기록은 브라우저와 origin별로 분리된다. 기기 간 공유, 계정 백업, 협업 동기화는 제공하지 않는다. 브라우저 데이터 삭제·시크릿 세션 종료에 따른 보관 제한을 README에 설명한다.
- 공통 이력 JSON은 **명시적으로 저장한 기록과 개정**을 포함한다. 저장 전 초안은 IndexedDB에 자동 보관되지만 이력 JSON에 포함되지 않는다. 초기화는 기록·초안·개정을 지우므로 필요한 초안은 먼저 검토 기록으로 저장해야 한다.
- 최초 담당자의 Chrome 파일 선택은 확장 프로그램의 파일 URL 접근 제한으로 `setFiles`가 거부되었다. 이후 통합 담당이 IAB의 실제 파일 선택기로 평판 CSV를 불러와 **4/4행 검수, 출처 재선택, 저장 성공**을 확인했다. 본 감사에서는 제출물 QA의 `root/csv-upload-saved.png`를 직접 열어 파일명·CSV 4행·합성 출처·저장 완료를 확인했다. 따라서 앱의 CSV 파일 업로드는 통합 검수 통과이며, 초기 실패는 해당 Chrome 검수 환경의 제한으로 기록한다.

## 공개 파일과 검사 한계

- 보완 후 `public/`에는 GS SVG 2개, Pretendard 폰트와 라이선스, 실행 라이브러리 고지 5개와 종합 고지 파일이 있다. `dist/`에는 앱 번들·같은 공개 자산·버전 파일이 있다. 소스맵, 원본 PDF/HWP/DWG/DXF/정사영상/GPR 원자료, 세션 로그는 없었다. 공개 자산과 빌드 경로에 심볼릭 링크도 없었다.
- 비공개 참고·회귀·좌표 전사·정합 작업은 앱 저장소 밖의 로컬 작업 폴더에 남아 있다. Git 추적 목록에 포함되지 않는다. `.gitignore`는 환경 파일·로그·개발 의존성·빌드를 제외하고, `.vercelignore`는 `work`·Git·개발 의존성·로그를 제외한다. Vercel 출력은 `dist`다.
- 형식 기반 키/개인정보 검색, 알려진 원문 식별자 및 좌표 문자열 비교, 이미지 해시 비교와 출처 코드 검토를 수행했다. 알 수 없는 모든 비밀 형식이나 숫자를 완전히 판별했다는 의미는 아니다. 탐지된 비밀값을 출력하거나 원문을 이 문서에 복사하지 않았다.
- 감사 이후 생성되는 문서·첨부·파일은 이 스냅샷의 검사 결과에 포함되지 않는다. 최종 파일 목록을 대상으로 같은 검사를 한 번 더 수행하고, 위 미해결 항목 및 최종 SHA를 갱신한다.

## 공개 배포 후 확인

기능 완성 commit `46c852ab58feb69682214cc570cf9552b191ef0c`의 Production을 인증 없는 HTTP로 확인했다. 8경로와 정적 자산11개가 정상이며 HTML/version commit 일치. 인증 없는 fresh git clone에서 lockfile 설치·74시험·빌드도 통과했다. 마지막 단면 축 단위 위치 수정 후의 최종 SHA/재검증은 제출 패키지 배포 기록에 보존한다. 공개본이 생성한 HTML/JSON에는 합성 출처만 있고 원문명/sourceInput/사용자 경로가 없음을 확인했다.
