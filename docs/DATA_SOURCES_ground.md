# 지반 모델 데이터와 계산 방법

현재 로컬 AutoGeo 지반 모델의 기본 자료는 **이천자이더리체 실제 현장**이다. 기존 공개 URL은 이전 합성판이며 현재 실제 전사값·좌표·정사영상의 외부 공개는 승인 전이다. 실제 수치와 경량화 공간 자산은 로컬 앱에 통합했고, 아래 합성 예제는 별도 버튼으로 구분한다.

## 현재 실제 원자료

- 2021.02 3공, 2022.01 14공, 2022.08 11공, 2023.11 4공: 총 32공·96개 가변 층구간. `src/data/real-ground/boreholes.json`에 차수별 고유 ID·좌표·표고·층구간·원문 페이지·출처 SHA256을 보존한다.
- 로컬 원자료본은 실제 주상도 PDF47쪽을 이미지와 PDF로 열람한다. 파생자료 모드는 원문 이미지를 요청하지 않고 출처·페이지·전사 층서와 로컬 원문 안내를 표시한다.
- 기본 보간 모델은 2022.08 11공이다. 4차수 전체를 비교할 수 있으나 서로 다른 시점의 공구 표고가 혼재한다. 공구 표고·풍화토 상단·암반 출현면을 추정하며 최하단 관찰 종료심도를 암반 바닥으로 만들지 않는다. 공별 주상도는 실제 관측한 가변 층서를 유지한다.
- NH-4(2022.01)의 기재 총심도20m와 층표 관찰 종료30m 충돌을 보존한다. 오류를 임의 수정하거나 적합으로 판정하지 않는다.
- 현장 프레임은 `icheon-local-m`, ENH 원점은 `[239800,521450,0]`m다. E=원문Y, N=원문X 값을 보존한다. 드론 EPSG:5186은 원본 메타데이터 근거가 있지만 시추 좌표계 명시는 미확인이다.
- 실제 정사영상(WebP·64타일), DSM101×101 표면, LAS 공간 대표103,763점, CAD7,988엔티티·8레이어와 GCP13점을 연결했다. TFW와 GeoTIFF affine의 최대 차이1.17e-10 이내를 확인했다.
- 드론 촬영일·수직기준·영상 독립 검사점은 미확인이다. DSM/LAS와 과거 공구표고의 차이는 침하량이 아니다. KNGeoid18은 존재를 기록하되 임의 높이 변환에 적용하지 않았다. CAD 변환 잔차는 같은 도면 내부 검산이며 현장 측량 정확도가 아니다.

`public/documents`, `public/data/ground/logs`, `public/data/field/quality`의 제공 원문은 로컬에 유지하며 `node scripts/build-derived.mjs`는 생성된 dist에서만 제외한다. 실제 좌표·정사영상·수치는 파생자료 모드에도 남으므로 외부 공개 범위를 따로 확인한다.

## 별도 합성 예제 · 초기 공개판의 데이터

- 120 × 100 m 현장 로컬 좌표계. E는 동쪽, N은 북쪽, 표고와 심도는 m이다.
- 관측공 12개(BH-01~12). `src/features/ground/engine.mjs`의 `trueHorizons()`에서 표고와 네 연속 층구간을 생성한다.
- 지층 이름은 매립층·퇴적층·풍화대·기반암이며 합성 예제의 구분이다. 실제 특정 현장의 층서로 해석하지 않는다.
- 굴착 영역 E 35~85 m, N 25~75 m. 기본 기준 지표 36 m, 굴착 깊이 10 m. 기준 지표는 굴착 저면을 정의하는 시연 기준이며 관측공별 공구표고를 바꾸지 않는다.
- 평면 정합에 쓰는 경계와 대응점도 합성이다. 적합점 P1~3과 계산에 사용하지 않은 검사점 C1~2를 분리했다. 공개 시연의 알려진 변환은 동쪽 +6 m, 북쪽 -4 m, 반시계 회전 7°, 등방 축척 0.96이다.

## Ordinary kriging

지층 경계 **표고**를 ordinary kriging으로 계산한다. 관측공 사이의 단순 선형 연결이나 IDW를 kriging으로 표시하지 않는다. 동일한 관측 위치·베리오그램에서는 각 경계에 동일한 가중치를 사용한다.

```text
[ Γ  1 ] [ w ] = [ γ(query) ]
[ 1ᵀ 0 ] [ μ ]   [    1     ]
prediction = Σ wᵢ zᵢ
variance   = Σ wᵢ γᵢ + μ
```

가중치 합은 1이다. 부분 피벗을 쓰는 행렬 역산으로 풀며 특이행렬이면 원인을 표시하고 계산하지 않는다. 외삽 여부는 관측공의 볼록경계로 구분한다. 층경계 교차를 검출하고 임의 정렬·두께 보정으로 숨기지 않는다.

현재 실제 모델 기본 설정: 구형 베리오그램, range 150 m, **부분 문턱값** 50 m², nugget 0 m². 별도 합성 예제는 range95m·부분 문턱값4m²·nugget0m²를 쓴다. 사용자가 고른 가정이며 데이터에서 자동 최적화한 매개변수는 아니다. 지원 식은 `u = distance / range`일 때 다음과 같다.

- 구형: `nugget + psill × (1.5u − 0.5u³)` for u<1; 이후 `nugget + psill`.
- 지수형: `nugget + psill × (1 − exp(−3u))`.
- 가우시안: `nugget + psill × (1 − exp(−3u²))`.
- 거리 0의 반분산은 0으로 둔다. 입력 위치를 정확히 재현하는 정책이며 nugget을 측정오차로 보아 관측값을 평활화하는 모드는 제공하지 않는다.

구형·지수형 및 partial sill 개념은 [PyKrige 공식 베리오그램 문서](https://geostat-framework.readthedocs.io/projects/pykrige/en/stable/variogram_models.html)를 참고했다. 가우시안의 range 상수는 구현마다 다를 수 있으며 AutoGeo는 위 식의 3을 명시적으로 사용한다. PyKrige 런타임에 의존하지 않는 별도 구현이다. 관측값 재현과 nugget 처리의 차이는 [PyKrige OrdinaryKriging 공식 설명](https://geostat-framework.readthedocs.io/projects/pykrige/en/stable/generated/pykrige.ok.OrdinaryKriging.html)의 `exact_values` 구분과 함께 확인할 수 있다.

## 검수 수치의 의미

- LOO: 한 공을 제외한 나머지 공으로 제외공 위치를 예측한다. 실제 모델은 공구표고·풍화토 상단·암반 출현면별 예측−관측 RMSE를 표시한다. 3개 이하 공에서는 LOO를 산출하지 않는다. 기본 2022.08 모델의 세 값은 약1.69/1.57/4.16m이며 측량 정확도나 설계 적합 판정이 아니다.
- 실제 4차수와 전체32공 모델의 JS 풀이를 독립 NumPy 풀이와 845위치·2,535경계값에서 비교해 최대 높이 차이5.97e-13m를 확인했다. 이는 계산 구현의 일치 검증이며 실제 지반 정답 검증은 아니다.
- 합성 참값 오차: 예제를 생성한 식의 내부 경계 3개와 693개 격자점의 추정값을 비교한다. 기본 fixture의 RMSE 약 0.10477 m, LOO RMSE 약 0.31781 m이다. 실제 현장 정확도 값이 아니다.
- 크리깅 분산: 관측 위치와 설정한 베리오그램에 따른 모델 분산이다. 현장 정확도 %, 안전율, 신뢰도 %로 표시하지 않는다.
- 지층 경계 추정은 설계 지반정수·안정성 검토를 자동 생성하지 않는다.

## 좌표와 정합

실제 공간 정합은 ENH 원점에 대한 로컬좌표에서 평면 이동·회전·축척을 적용한다. 주상도 기준으로 적용하는 평면 변환은 `E′=s cosθ E−s sinθ N+tE`, `N′=s sinθ E+s cosθ N+tN`이다. 원점·3×3 행렬·역행렬·적용 상태와 확보된 근거를 검토 기록에 저장한다. 실제 영상은 독립 검사점이 없어 검사 RMSE를 만들지 않는다. 별도 합성 예제만 알려진 적합점/검사점 잔차를 제공한다. 클릭은 SVG의 화면 변환을 먼저 되돌린 다음 이 평면 변환의 역행렬로 원형상 좌표를 구한다.

시추공 위치·공구표고·층경계는 정합으로 수정하지 않는다. 높이 offset은 수평 변환과 별도이며 공개 평면도에는 적용하지 않는다고 표시한다. 자산 원점 → 보정 → 장면 원점을 한 번씩 적용하는 3D 변환과 역변환은 알려진 좌표로 테스트했다. Three 장면 축은 `(E,H,−N)`이며 높이 표시 배율은 계산값에 적용하지 않는다.

## 입력·저장 범위

별도 합성 예제의 CSV/JSON 입력은 합성 m 프레임과 네 연속 층구간 계약이다. 실제 모드는 검수한32공 스냅샷·가변 층구간·차수·원문 근거를 저장/복원하며 원자료 수치가 달라진 기록을 동일 자료로 조용히 채택하지 않는다. 실제 층서를 합성 네 층으로 자동 축약하지 않는다. 중복 위치·공번, 층 순서 역전·공백, 빈 숫자, 단위 누락을 거부한다. 실제 불확실한 지층경계를 시추종료심도로 대체하지 않는다.

입력 초안은 브라우저 IndexedDB에 보관한다. 명시적으로 저장한 모델은 원자료·계산 설정·정합·보기 설정을 포함하며 저장된 기록에서 다시 불러올 수 있다. 전역 JSON 이력 내보내기/가져오기와 연결된다. 가져온 값은 계산과 3D에 전달하기 전에 다시 검수한다.

## 재사용과 한계

Three.js/OrbitControls로 실제 자료용 React 화면을 구현했다. 기존 프로젝트의 좌표 관례·정합 구성을 참고하고 현재 제공 DWG와 해시가 같은 CAD 파싱 결과를 재사용했다. 실제 원문은 로컬 전용 모드에, 경량화 영상·DSM·점군·CAD는 실제 파생자료 후보에 통합했다. 원본 대용량 파일 전체나 처리 API를 복사한 것은 아니다. 서버나 외부 AI API 없이 브라우저에서 계산한다. WebGL을 만들지 못하면 안내와 같은 모델의 SVG 단면·시추표를 제공한다.

이 시제품은 지층의 개략 분포와 검토 근거를 탐색하는 도구다. 원자료 확인과 전문적 해석을 대체하는 지반 설계 인증 도구가 아니다.
