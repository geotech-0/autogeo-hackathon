# AutoGeo

입찰·설계·시공·유지관리의 자료, 계산 근거와 검토 이력을 하나의 현장·구역으로 연결하는 해커톤 시제품입니다.

[공개 데모](https://autogeo-hackathon.vercel.app/) · [소스 저장소](https://github.com/geotech-0/autogeo-hackathon)

## 대표 흐름

1. A현장의 시추공 12개와 ordinary kriging 지층·단면을 확인합니다.
2. 앵커의 수동 최대반력을 바꾸고 Treq→손실 포함 Jf→띠장 전달하중과 단계별 검토를 확인합니다.
3. 평판재하·계측 예제에서 기준 초과를 검토하고 구역 이슈를 저장합니다.
4. GPR 해석결과의 확인·조치·재점검을 기록하고 통합 이력에서 출처와 개정을 확인합니다.

공개 기본 자료는 모두 합성 A현장입니다. 주상도 원문·실제 현장명/좌표·도면·정사영상·세션 로그는 포함하지 않습니다. GS 디자인 참고를 적용했으며 기업 공식 운영 서비스가 아닙니다.

## 실행과 검증

Node.js 22.12 이상과 npm을 사용합니다. 이번 실행 환경은 Node 25.9입니다.

```sh
npm ci && npm run dev
```

```sh
npm test
npm run build
npm run preview
```

Vite/React/TypeScript 정적 앱이며 API 키·서버·상용 해석기 설치가 필요하지 않습니다. Vercel의 build command는 `npm run build`, output은 `dist`입니다. SPA 경로 새로고침은 `vercel.json`에서 처리합니다. 배포 commit은 `/version.json`과 HTML의 `autogeo-build` 메타데이터로 확인합니다.

## 구현 범위

- **입찰**: 선정 건설기준의 개정고시 메타데이터와 공식 링크, 현장 적용판·조항 메모. 시추 CSV/JSON 검수, 구형·지수형·가우시안 베리오그램 ordinary kriging, 3D·단면·LOO·합성 참값 오차, 참고형상 이동/회전/등방축척과 역변환.
- **설계**: 앵커·띠장·H-Pile·토류판의 선정 검토법. 편집 허용 변수와 수동 외부 해석값, 단위·모델/자료 개정, 영향 변수 변경 시 재확인, 단계별 수식/대입/판정, 검토안·대안 비교와 HTML 계산서.
- **시공**: 평판재하 CSV의 하중/압력·면적·침하·시간, 계측 CSV/수동 기록과 기준, 합성 평면영상 2회차 비교와 주석.
- **유지관리**: 이미 해석된 GPR 이상구역과 조사→확인→조치→재점검 이력, 보관/복원.
- **공통**: IndexedDB 저장, 개정 보존, JSON 내보내기/가져오기, 출처·가정·현장·구역 이력.

## 데이터 보관

기록은 현재 브라우저·현재 도메인에 저장됩니다. 다른 브라우저와 자동 공유되지 않으며 시크릿 모드를 닫거나 브라우저 데이터를 지우면 사라질 수 있습니다. 통합 이력에서 JSON으로 보관하고 다시 가져오세요. 가져오기는 같은 개정의 내용 충돌을 거부하고 최신 기록을 과거 개정으로 덮어쓰지 않습니다. 초기화는 확인 후 수행합니다.

통합 JSON에는 **저장한 결과와 개정 이력**이 포함됩니다. 화면에서 작성 중인 임시 입력은 포함되지 않으므로 먼저 검토 결과를 저장하세요. 설계 화면의 입력 JSON은 별도로 현재 설계 입력을 보관합니다.

## 해석 범위

부재 검토는 사용자가 채택한 외부 탄소성해석 결과를 사용합니다. 해석기를 실행하거나 흙막이 전체 안정성을 자동 판정하지 않습니다. 원문 재현 회귀와 현행 기준 적합성 검토는 별개입니다. 기본 기준 메타데이터는 확인한 2024년 개정고시이며 최신판 여부와 개별 본문 조항은 별도 확인해야 합니다.

크리깅 분산은 모델 가정에 따른 값이며 정확도 %가 아닙니다. 공간 맞춤은 주상도를 이동시키지 않습니다. 합성 2D 영상 비교로 침하량을 산출하지 않으며 GPR 해석결과의 위치·조치를 관리하고 원신호 자동 손상 판독을 하지 않습니다.

최종 검증 기록과 데이터 출처는 `TEST_REPORT.md`, `VISUAL_QA.md`, `DATA_SOURCES.md`, `DECISIONS.md`에서 정리합니다.
