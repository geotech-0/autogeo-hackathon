# AutoGeo

입찰·설계·시공·유지관리의 자료, 계산 근거와 검토 이력을 하나의 현장으로 연결하는 해커톤 시제품입니다.

현재 초기 통합 중입니다. 공개 데이터는 합성 A현장이며 실제 현장 문서·좌표·세션 로그는 저장소에 포함하지 않습니다. GS 디자인 참고를 적용한 해커톤 시제품으로 공식 운영 서비스가 아닙니다.

## 실행

```sh
npm ci
npm run dev
```

## 빌드

```sh
npm run build
npm run preview
```

React·TypeScript·Vite 정적 프런트엔드. 검토 기록은 브라우저 IndexedDB에 보관하며 JSON으로 내보내고 가져올 수 있습니다. 외부 AI API 키가 필요하지 않습니다. 별도 브라우저 간 기록은 자동 공유되지 않습니다.

공개 배포 및 실제 검증 결과는 통합 완료 후 갱신합니다.
