# AutoGeo · 이천자이더리체

입찰·설계·시공·유지관리의 원자료, 계산 근거와 검토 이력을 하나의 현장에 연결하는 해커톤 웹 앱입니다. 현재 작업본은 사용자가 제공한 이천자이더리체 실제 자료를 기본으로 사용합니다.

## 공개 버전 확인

공개 대상은 실제 수치·좌표·영상·3D를 포함한 파생자료 앱입니다. [Vercel 공개 주소](https://autogeo-hackathon.vercel.app/)의 배포 소스는 [공개 version.json](https://autogeo-hackathon.vercel.app/version.json)의 커밋 SHA를 [GitHub 저장소](https://github.com/geotech-0/autogeo-hackathon)와 대조해 확인합니다. 배포 진행 및 검수 결과는 `CHECKPOINT.md`에 기록합니다.

## 대표 흐름

1. 실제 정사영상 위에서 4개 조사차수의 32공을 선택하고, 해당 주상도 원문과 관측 구간을 확인합니다.
2. 같은 조사차수의 지층을 채운 3D 메쉬와 단면으로 검토하고 실제 DSM·점군·CAD 형상과 구분합니다.
3. 구조계산서 B좌/C/D 중 위치와 앵커 단을 선택합니다. GEOX 화면에 있는 허용 항목과 외부 해석의 최대값을 수정하면 식·수치 대입·비교 결과가 갱신됩니다.
4. 월간 계측보고서 1–3월의 27개 센서에서 실제 수치와 원문을 비교하고, 자료 불일치나 이상을 담당자의 확인·조치 기록으로 연결합니다.
5. 조사자료를 첨부해 유지관리 기록을 등록하고 확인·조치·재점검·마감을 남깁니다. 통합 이력에서 개정과 원문 첨부를 다시 열고 JSON으로 보관합니다.

품질시험의 **내 시험자료 검토**에서는 평판재하 CSV를 불러오고 단위·판 직경·관리기준을 확인해 원시 행, 곡선과 결과를 저장합니다. 추가 계측은 사용자가 직접 확인한 기준으로 비교하고 초과 내용을 조치 이력에 연결합니다. 센서별 작성 초안을 보존하며, 자동 입력되는 조치 날짜는 한국 시간 기준입니다.

## 실행

Node.js 22.13 이상과 npm이 필요합니다. PDF.js 6의 실행 요건을 포함한 버전입니다.

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

Vite/React/TypeScript 정적 앱이며 API 키·상용 해석기·서버 설치가 필요하지 않습니다. 위 `npm run build`는 로컬 원문을 포함할 수 있는 작업본 빌드입니다. 공개용 빌드는 다음 명령으로 만듭니다.

```sh
node scripts/build-derived.mjs
```

Vercel build command도 `node scripts/build-derived.mjs`이며 output은 `dist`입니다. 이 명령은 실제 전사 수치·정사영상·공간자료를 유지하고 생성된 출력에서 제공 원문 PDF·주상도 이미지·품질 원본을 제외합니다. 로컬 원본은 보존합니다. SPA 새로고침은 `vercel.json`으로 처리합니다. 배포 소스는 `/version.json`과 HTML `autogeo-build` 메타데이터로 확인합니다.

## 제공 자료와 구현

| 업무 | 실제 연결 내용 | 사용자 확인이 필요한 범위 |
|---|---|---|
| 지반 | 4차수 32공·96구간, 원문 주상도 47쪽, Ordinary kriging 3D·단면·공 제외 교차검증 | NH-4 총심도와 층서 모순, 시추 좌표계 명시 미확인 |
| 드론·공간 | 실제 정사영상과 확대 타일, DSM, LAS 공간 대표점 103,763개, CAD 도면선, GCP 13점 | 영상 촬영일·수직기준 미확인, 독립 영상 검사점 미확보. 단일 회차로 변형량을 만들지 않음 |
| 설계 | B좌/C/D 7개 검토안과 20개 원문 부재 사례, 앵커·띠장·H-Pile·토류판의 수동 입력·연결 계산 | D 단면 깊이 모순 보존. 외부 탄소성해석 실행 및 흙막이 전체 자동 안정판정은 지원 범위 밖 |
| 계산서 추가 검토 | 사면·근입장·보일링·침하·직접기초·말뚝·영구배수의 원문 결과와 페이지 | 원문 결과 검토이며 해당 항목의 재해석 엔진은 아님 |
| 계측 | 보고서 3권, 27센서, 747개 날짜별 대표 관측과 원시 관측·심도 프로파일 | 유량 요약/상세표·단위 모순, 계기값 감소, 일부 센서 기준 연결을 보류 상태로 유지 |
| 품질시험 | 제공 ZIP 7파일의 평판·말뚝·인장·DCPT 참고자료와 수치 곡선 | 다른 현장 또는 출처 미상 예제. DCPT는 상관표이고 실제 심도별 타격수가 아님 |
| 유지관리 | 실제 자료 첨부 등록, 위치 선택, 확인·조치·재점검·보관·복원 | 제공된 GPR 실측자료 없음. 원신호 판독이나 손상 확정을 자동으로 수행하지 않음 |
| 기준·자료함 | 현장 PDF 9개 직접 열람, 출처 목록과 계산서 채택 기준·원문 페이지 | 계산서 채택판과 현행 최신 기준 적합성은 별개 |

지반의 합성 예제는 별도 버튼으로만 열립니다. 실제 자료를 익명화했다는 이유로 합성으로 부르지 않습니다. 제공 GEOX 캡처는 편집 항목을 정의하는 참고이며, 초기 설계 수치는 실제 구조계산서를 따릅니다.

## 저장과 복원

기록은 현재 브라우저·현재 도메인의 IndexedDB `autogeo-icheon-v2`에 보관됩니다. 이전 합성 DB는 보존되며 혼입하지 않습니다. 다른 브라우저와 자동 공유되지 않습니다.

통합 JSON은 저장한 결과, 모든 개정과 연결 첨부 바이트·SHA-256을 포함합니다. 가져오기는 다른 현장, 같은 개정의 내용 충돌, 위변조 첨부나 누락 참조를 거부하며 기존 최신 기록을 과거 개정으로 덮어쓰지 않습니다. 첨부는 파일당 25MB, 내보내기 총 첨부 100MB 이내입니다. PDF·PNG·JPG·WebP·CSV·TXT·JSON을 지원합니다. 화면의 작성 중 초안은 통합 JSON에 포함되지 않으므로 검토 결과를 먼저 저장하세요.

지층은 표층 복합층·풍화토·암반을 닫힌 메쉬로 표시합니다. 삼각형을 실제 시추공 분포 외곽에 맞춰 잘라 격자 계단을 없앴습니다. 암반 하부는 사용자가 조절하는 모델 표시 하한이며 관측된 암반 바닥이 아닙니다. X(E)·Y(N)·Z(EL.) 축의 슬라이더와 숫자 입력, 남길 방향, 단면만 보기, 위에서 보기·절단면 정면·자유 회전을 제공합니다. 아래 2D 단면은 동일 메쉬 절단 결과를 사용하며 절단을 끈 경우 참고 단면으로 표시합니다. 표층 복합층은 여러 원문 지층을 합친 개략 표현이고 개별 주상도는 원래 층서를 보존합니다. 메쉬 측벽은 모델 범위이며 실제 수직 지질 경계를 뜻하지 않습니다.

공간 좌표와 시기는 원본 정보와 사용자 정합을 구분해 보관합니다. 크리깅 분산은 선택한 모델 가정에 따른 값이며 측량 정확도나 설계 적합 인증이 아닙니다. 여러 조사차수를 섞는 경우 시점 혼재를 표시합니다.

자세한 출처는 `DATA_SOURCES.md`, 검증은 `TEST_REPORT.md`와 `VISUAL_QA.md`, 현재 릴리스 상태는 `CHECKPOINT.md`를 확인하세요. GS 디자인 참고를 적용했으며 기업의 공식 운영 서비스로 표시하지 않습니다.

모델 탐색기 조작은 [Seequent Leapfrog Geo 공식 Slicer 문서](https://help.seequent.com/Geo/2024.1/en-GB/Content/basics/slicer.htm)의 축별 절단·남길 방향·정면 보기 흐름을 참고했습니다.
