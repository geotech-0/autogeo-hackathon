# AutoGeo 주요기능 HTML 발표자료

5개 화면에서 3D 지층, 앵커→띠장 계산, 계측 위치·추세를 직접 조작합니다. 기존 앱·PDF·PPTX와 분리된 발표자료입니다.

## 재생성

프로젝트 루트에서 `npm ci` 후:

```sh
node scripts/presentation/export-demo-data.mjs
node scripts/presentation/build.mjs
```

결과: `public/data/presentation/index.html`. 이미지, Three.js, 데이터, 계산 엔진을 한 HTML에 포함하여 로컬에서도 엽니다. 외부 링크만 인터넷 연결이 필요합니다. 최신 브라우저와 WebGL을 권장합니다.

## 발표

약 3~4분. 화살표 키로 장을 넘기고 각 화면의 `발표 노트`를 참고합니다. 3D는 드래그로 회전, Z 슬라이더로 절단하고 대지경계를 중첩합니다. 설계는 45.62→60 kN/m 변경으로 연결 부재의 결과를 비교합니다. 계측은 INC-1/F-2를 전환합니다. 마지막 카드는 기능 설명용으로 실제 현장 조치 기록이 아닙니다.

## 자료 범위

현장명은 ‘이천 OO현장’으로 표기했지만 수치와 형상은 기존 공개 파생자료 기반입니다. 합성·완전 익명 데이터로 소개하지 않습니다. 앱의 실제 계산 엔진과 메쉬 절단 함수를 직접 재사용합니다. 원문 PDF나 개인 연락처는 포함하지 않습니다.

- 지층: 2022.08 11공, 65×65 격자. 전체 32공과 CAD 경계 범위+10m 사각 모델. 시추공 밖 외삽 및 암반 바닥 표시하한 EL.30m. 높이 1.5배. 평면도의 원은 시추공 위치이며 해당표고 관측 존재를 뜻하지 않습니다.
- 설계: B-B′ 좌측 앵커 1단. 제원을 고정하고 수동 채택 축방향 반력만 변경합니다. 외부 해석을 재실행하거나 전체 흙막이 안정성을 판정하지 않습니다.
- 계측: INC-1 25개 제공 시계열, F-2 원시 일유량. null·음수 보존. F-2는 기준 단위 불일치 등으로 판정 보류. 도면상 상대 위치이며 측량 좌표가 아닙니다.
- 이 HTML 조작은 기록을 저장하지 않습니다. 공개 앱의 브라우저 저장 기능과 별개입니다.

3D 라이브러리 Three.js MIT 라이선스는 `three-license.txt`와 HTML 자료 안내에 포함합니다.
